Early preview for Windows 10 and 11

Set it down. Pick it up anywhere.

Cairn is a drop shelf for Windows. Drag files, text or links to the edge of your screen to park them, then drag them out into any app when you're ready.

Get Cairn View source

How it works

  1. 1

    Drag to the edge

    Drag anything to the side of your screen. A slim tab grows into a drop zone, and the item is parked.

  2. 2

    Keep working

    Switch apps, close windows, restart. Your stack stays put until you remove things.

  3. 3

    Drag it out

    Open the stack with a click or Ctrl Alt C, select one item or several, and drag them into any app.

Built to stay out of the way

Real file drops

Files arrive as normal file drops, so Explorer, browsers and mail clients all accept them. Several at once, even from different folders.

Your files stay put

Cairn keeps references and always asks to copy, never move. Nothing is uploaded and there's no account.

Private by default

The stack is stored on your PC, encrypted with Windows DPAPI, in your own profile.

Tiny and native

A 331 KB Rust app using about 18.5 MB of memory and no CPU while idle. It looks like it shipped with Windows.

Never in your game

The tab hides while a fullscreen app, game or presentation is up. No mouse hooks, so window drags never set it off.

Keyboard friendly

Arrows to move, Shift to extend, Ctrl A for all, Enter to open, Del to remove. Text items paste into the app you came from.

Get Cairn

Cairn is in early development. There is no installer or signed download yet; those come with the private beta. Until then you can build it from source with a stable Rust toolchain.

Needs Windows 10 (19045 or later) or Windows 11.

git clone https://github.com/mahmoudalnkeeb/cairn
cd cairn
cargo build --release
target\release\cairn.exe
